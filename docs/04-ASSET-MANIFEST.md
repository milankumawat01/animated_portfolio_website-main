**Needed by:** P3A (hero strip), P3E (skills graph)

**Do not source these manually.** P0 installs `simple-icons`, which ships the
official SVG for nearly all of them. P5 bakes the needed marks into a single

Claude, Gemini, LangChain, LlamaIndex, Next.js, React, TypeScript, Tailwind CSS,
HTML5, CSS3, Supabase, Convex, Cloudflare, Firebase, Docker, Nginx, Vercel,
DigitalOcean, Ubuntu, GitHub, Postman, Figma, Resend, VS Code, Notion.

🟡 **Milan supplies only the ones `simple-icons` lacks.** P0 produces that gap list.
Expect FastAPI, Claude, Convex, and RAG to need hand-supplied SVGs at 128×128.
